** Running

Then you can run:
#+begin_src shell
  make dev
  # or nix run .# -- "resources/config/run-local.toml"
#+end_src

The API will start at port ~50051~ according to the .toml configuration file. If you visit the ~/swagger.json~ route you will obtain the Swagger API specification for the JDB API.

You will need a PostgreSQL database running and a Redis instance too:
#+begin_src shell
  make spin-up-containers-local
#+end_src

*No secrets* are stored in config files. We only store the location of files containing secrets. Thus, some secret files are needed.
#+begin_src shell
  touch "resources/secrets/postgresql"
  touch "resources/secrets/redis"
  touch "resources/secrets/amazonses"
#+end_src

You can connect to the local development PostgreSQL database to put some data in or other purposes.
#+begin_src shell
  psql -U jdbapi_admin jdbapi_database -h localhost -p 54432
  # list all tables with \dt
  # get table info with \d+ table_name
  # list all schemas with \dn
#+end_src

Bear in mind the JDB API also takes care of schema migrations of the database.
